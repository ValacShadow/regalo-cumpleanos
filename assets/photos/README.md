# Your photographs go here ♡

Replace the example photo paths configured in `config.js` with the names of your own photographs.

Starter paths:
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

These files are intentionally not included, so you can add your own photos without any invented person or image. Supported browser image formats include JPG, PNG, and WebP. Keep the filenames and paths in `config.js` in sync.
